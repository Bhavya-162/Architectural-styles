# Architectural Styles — Seminar Website

A responsive, interactive Software Engineering seminar website built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — website structure and content
- `style.css` — dark developer theme and responsive layout
- `script.js` — style tabs, clickable architecture diagrams, step walkthroughs, and revision quiz

## Run it
1. Download and extract the ZIP.
2. Open the `architectural_styles_seminar` folder.
3. Double-click `index.html` to open it in a modern browser.

No server, database, or installation is required. Google Fonts are loaded from the internet; system fallback fonts are used if unavailable.

## Included styles
1. Data-centered
2. Data-flow (pipes and filters)
3. Call-and-return (including remote procedure calls in the explanation)
4. Object-oriented
5. Layered
6. Model–View–Controller (MVC)

The examples are illustrative teaching scenarios. Real applications may combine multiple architectural styles.
